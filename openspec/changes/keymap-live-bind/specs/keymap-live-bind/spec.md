## ADDED Requirements

### Requirement: Bind wizard for Postgres source KeyMaps

The system SHALL provide a bind wizard when creating or rebinding a KeyMap with `storage=source` that selects connection, schema.table, From column, To column, and a whitelist of editable attribute columns.

#### Scenario: Default editable columns

- **WHEN** the wizard loads table columns
- **THEN** From and To are chosen explicitly
- **AND** editable attributes default to all non-autogenerated columns except From/To
- **AND** serial/identity columns are excluded by default

### Requirement: Source maps do not store the full dictionary in the project

For `storage=source`, the project IR SHALL treat the warehouse table as SoT and MUST NOT require the full row set in `KeyMapDef.entries` for correct preview or Save.

#### Scenario: Large map open

- **WHEN** a source KeyMap is bound to a large Postgres table
- **THEN** the editor loads rows via paged/filtered reads
- **AND** Save sends only a dirty delta (upserts + deleted froms)

### Requirement: Upsert-by-from write-back

Source Save SHALL upsert by the From column (batched), delete removed From keys, and MUST NOT full-wipe the table or overwrite unselected/autogenerated columns on UPDATE.

#### Scenario: Extra column preserved

- **WHEN** a row is updated and a column is not in `editable_columns`
- **THEN** that column’s value in Postgres remains unchanged after Save

#### Scenario: NULL editable attrs round-trip

- **WHEN** an editable attribute is SQL NULL in Postgres
- **THEN** read omits or nulls that attr (does not coerce to empty string)
- **AND** a subsequent Save that does not set that attr writes SQL NULL (not `''`)

#### Scenario: Typed column cast on write-back

- **WHEN** From, To, or an editable column has a non-text Postgres type
- **THEN** Save CASTs VALUES cells to that column’s type (empty non-text → NULL)

### Requirement: Preview joins live source maps

When applying a source-backed KeyMap in DuckDB preview, the system SHALL join the attached Postgres map relation for From→To remap rather than embedding the full dictionary as VALUES.
