# Whole-mapping quality lab

Provide a distinct macro view next to the existing local Join Lens. Show patterns
that coverage alone hides, using a reproducible 100K-position offline Help lab.

In scope: deterministic Rust data generation, genuine seed mapping/Join, full-data
aggregates, family/grade/basis matrix, row-share/revenue views, target concentration,
exact sample-key drill-down and a persistent workspace overview tab.

Out of scope: replacement of Join Lens, the rejected card editor, new LLM calls,
a universal quality classifier, general metadata binding and new mapping IR.
