# Design: Reconciliation task card

Keep a tiny task session in the existing App composition, keyed by project UID.
Initialize only in the successful canonical flagship load commit; clear in the
shared project application path. Store no data rows or graph copy. A pure helper
validates query/Join targets and owns scenario instructions, not catalog metadata.

Render a small component above canvas/dock only while Pipeline canvas is active.
Dismiss keeps a local Lab task restoration control. Show me uses existing query
selection, actual Join index and step editor synchronization, then Data/Lens.
No layout maximize/collapse, timer, overlay, host change or special preview policy.

Test target resolution and session ownership with unit tests, real offline load,
CTA/Dismiss/restoration/switch-away with Electron, and capture the running UI.
