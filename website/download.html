From source

Build the desktop app locally

Prerequisites: Git, Node.js 20+, npm, stable Rust, and Python 3 with venv support. For a local dbt tree while developing, run the fetch script—or use Install for me after first launch. 

git clone https://github.com/dwhforge/query.git
cd query
./scripts/fetch-duckdb-extensions.sh
# optional: ./scripts/fetch-dbt-venv.sh
npm install
npm run electron:dev
